# Helena Duarte Advocacia (exemplo)

Landing page de exemplo para advocacia de família e sucessões, criada por Marlon Franco para o portfólio. O nome, os dados e os números de registro são fictícios.

## Estrutura

```
index.html   a página inteira (HTML, CSS e JavaScript no mesmo arquivo)
img/         fotos usadas na página
```

## Publicar

É um site estático: suba esta pasta inteira em qualquer hospedagem (Netlify, Vercel, GitHub Pages ou `public_html` de uma hospedagem comum).

Depois de publicar:

1. Copie o endereço do site e cole no cartão correspondente do portfólio, no `index.html` do portfólio.
2. No `index.html` deste exemplo, troque `SEUDOMINIO.com.br` pelo endereço do seu portfólio. É o link "Voltar ao portfólio" da faixa no topo.

## Detalhes

- **Marcado como exemplo:** a faixa no topo avisa que é um projeto de exemplo, e a página tem `noindex` para não aparecer no Google como se fosse um negócio real.
- **Fontes:** Newsreader e Figtree, gratuitas no Google Fonts.
- **Fotos:** Unsplash, sob a licença do Unsplash (uso comercial gratuito, crédito não obrigatório). Fotógrafos: Christina @ wocintechchat.com. O crédito também está no rodapé da página.
- **Pessoas nas fotos:** não são profissionais com esses nomes. Se vender este layout a um cliente, troque pelas fotos dele.
